# DeepSeekBot Mascot

A bilingual community helper for DeepSeekBot and BotHarness, built on DeepSeek Harness (DSH). It helps with installation, model providers and supported integrations, and distinguishes verified behavior from unknowns.

This is a public PersonaBot Memory Repository and a live sample for the BotHarness Marketplace. `PERSONA.md` is stored at the repository root so the Git-URL install path can load the persona correctly. Public technical community knowledge may be added as Markdown memory files over time.

## Install

Open the **Bot Marketplace** in DeepSeekBot, find **DeepSeekBot-Mascot**, and choose **Install**. You can also create a PersonaBot from this repository's Git URL. Configure your own model provider and messaging connections after installation; no credentials or connected identities are included.

## Publication boundary

Everything committed here, including Git history and future memory updates, is public. This repository contains public technical knowledge only. API keys, tokens, personal details, private conversations and operator notifications must never be stored here. Server configuration, credentials and the private Operator Bot live outside this repository.
